# 爱好内容更新说明

爱好页路径：`/hobby`

爱好内容主要由 `content/hobby/` 维护。

## 目录结构

```text
content/hobby/
├── profile.json
├── featured.json
├── cards.json
└── monthly/
    ├── 2026-01.json
    ├── 2026-02.json
    ├── 2026-03.json
    └── 2026-04.json
```

读取逻辑：

```text
src/lib/content/hobby.ts
src/lib/data/hobby.ts
src/app/hobby/page.tsx
```

## profile.json

文件：`content/hobby/profile.json`

用于维护爱好页顶部简介、外部链接和游戏资料。

字段说明：

- `intro`：页面顶部简介
- `externalProfiles.goodreads`：Goodreads 链接
- `externalProfiles.letterboxd`：Letterboxd 链接
- `lolProfile.server`：LOL 服务器
- `lolProfile.rank`：段位
- `lolProfile.mainRoles`：主位置数组
- `lolProfile.championPool`：英雄池数组
- `lolProfile.currentInsight`：当前游戏相关说明

修改页面顶部简介时，改 `intro`。

修改外部链接模块时，改 `externalProfiles`。

修改游戏卡片里的资料时，改 `lolProfile`。

## featured.json

文件：`content/hobby/featured.json`

这是爱好页“我的精选”模块的主要数据源。页面会优先使用 `featured.json`；只有当它为空数组时，才回退到 `cards.json`。

结构：

```json
[
  {
    "title": "阅读",
    "items": [
      {
        "name": "契诃夫《第六病室》",
        "why": "推荐理由。"
      }
    ]
  }
]
```

字段说明：

- `title`：分类标题，当前建议使用“阅读”、“电影”、“游戏”
- `items`：该分类下的条目
- `items[].name`：书名、电影名或游戏名
- `items[].why`：展示在卡片里的说明
- `items[].rating`：可选，评分
- `items[].date`：可选，日期
- `items[].fullWhy`：可选，完整说明

注意：游戏分类标题需要保持“游戏”，这样页面才会在该卡片下显示 `lolProfile`。

## cards.json

文件：`content/hobby/cards.json`

当前是备用数据源。因为 `featured.json` 已有内容，页面不会显示 `cards.json`。如果想临时回退，可以把 `featured.json` 改成空数组：

```json
[]
```

一般更新时优先改 `featured.json`。

## monthly 月度更新

目录：`content/hobby/monthly/`

每个月一个文件，文件名必须是：

```text
YYYY-MM.json
```

例如：

```text
content/hobby/monthly/2026-05.json
```

文件内容：

```json
{
  "month": "2026-05",
  "reading": [
    {
      "name": "《书名》",
      "why": "页面摘要。",
      "fullWhy": "完整记录，可比 why 更长。"
    }
  ],
  "films": [
    {
      "name": "电影名",
      "why": "页面摘要。",
      "fullWhy": "完整记录，可比 why 更长。"
    }
  ]
}
```

字段说明：

- `month`：必须和文件名一致
- `reading`：当月阅读记录
- `films`：当月观影记录
- `name`：作品名
- `why`：短说明
- `fullWhy`：可选，完整说明
- `rating`：可选，评分
- `date`：可选，日期

页面显示规则：

- 页面只展示最新年份的月份标签
- 月份标签按从小到大排列
- 默认选中最新月份
- 每个分类默认显示前 2 条，多余内容折叠到“查看更多”
- 摘要展示时会通过 `src/lib/utils/hobbyExcerpt.ts` 截断 `fullWhy` 或 `why`

## 主页爱好卡片

爱好页由 `content/hobby/` 驱动，但网站主页 `/` 的爱好三张精选卡片仍在：

```text
src/app/page.tsx
```

搜索：

```ts
const hobbyistShowcaseCards
```

如果更换主页上的阅读、电影、游戏封面或文案，需要同步改这里。主页爱好图片常放在：

```text
public/assets/home/
```

## 更新后检查

```bash
npm run check:content
npm run typecheck
npm run dev
```

本地检查：

```text
http://localhost:3000/hobby
http://localhost:3000/hobby?month=2026-04#monthly-digest
```

重点检查：

- JSON 是否合法
- `monthly/YYYY-MM.json` 文件名和 `month` 字段是否一致
- “游戏”标题是否没有写错，否则 LOL 资料不会显示
- 最新月份是否出现在页面标签里
- 外部链接是否能打开
