# 主页内容更新说明

主页路径：`/`

主页文件：`src/app/page.tsx`

当前主页不是从 `content/` 自动读取的，而是直接在 `src/app/page.tsx` 里维护三组展示卡片和首页开头文案。适合少量、精选内容更新；如果以后希望完全后台化，再把这些数组迁移到 JSON。

## 主要更新位置

1. 首页开头文案

   文件：`src/app/page.tsx`

   搜索：

   ```tsx
   <h1>
   ```

   可更新内容：

   - 首页大标题：现在是“摄影，旅行，读书。”
   - 个人简介摘要：`home-hero-summary`
   - 头像：来自 `src/lib/data/profile.ts` 里的 `profile.avatar`
   - 个人信息：头像下方的姓名、身份、城市目前直接写在页面里

2. 主页摄影卡片

   文件：`src/app/page.tsx`

   搜索：

   ```ts
   const photographerShowcaseCards
   ```

   每张卡片字段：

   - `title`：卡片标题，例如“街拍”
   - `href`：点击跳转地址，例如 `/photography/street`
   - `image`：卡片图片路径，必须对应 `public/assets/...`
   - `alt`：图片替代文本
   - `quote`：卡片里的短句，支持换行
   - `body`：补充说明，支持换行
   - `imageClassName`：可选，调整图片裁切位置或缩放

3. 主页旅行卡片

   文件：`src/app/page.tsx`

   搜索：

   ```ts
   const travellerShowcaseCards
   ```

   每张卡片字段：

   - `place`：地点名称，例如“日本”
   - `href`：点击跳转地址，例如 `/travel/japan`
   - `image`：卡片图片路径
   - `alt`：图片替代文本
   - `body`：卡片说明文字，支持换行
   - `imageClassName`：可选，调整图片裁切位置
   - `bodyClassName`：可选，给某张卡片单独套样式

4. 主页爱好卡片

   文件：`src/app/page.tsx`

   搜索：

   ```ts
   const hobbyistShowcaseCards
   ```

   每张卡片字段：

   - `title`：卡片标题，例如“阅读”
   - `href`：点击跳转地址，例如 `/hobby#reading`
   - `image`：卡片图片路径
   - `alt`：图片替代文本
   - `body`：卡片说明文字，支持换行
   - `imageClassName`：可选，调整图片裁切位置或缩放

## 图片更新方式

主页图片都放在 `public/assets/` 下，常用目录：

- 头像：`public/assets/profile/`
- 摄影：`public/assets/photos/`
- 旅行：`public/assets/travel/`
- 爱好封面：`public/assets/home/`

在代码里引用图片时，不写 `public`，例如：

```ts
image: '/assets/home/ward-no-6-cover.jpg'
```

## 常见更新场景

### 修改首页简介

1. 打开 `src/app/page.tsx`
2. 修改 `home-hero-summary` 里的文字
3. 如果要同步修改头像信息，打开 `src/lib/data/profile.ts`

### 更换主页某张卡片

1. 把新图片放进 `public/assets/...`
2. 修改对应数组里的 `image`
3. 同时修改 `title`、`href`、`alt`、`body`
4. 如果图片主体被裁掉，微调 `imageClassName`

### 增减主页卡片

直接在对应数组里增删对象即可。主页当前每个模块按三张卡片设计，增加到四张以上时需要检查移动端和桌面端排版。
