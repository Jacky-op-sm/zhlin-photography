# 摄影内容更新说明

摄影首页路径：`/photography`

摄影分类页：

- `/photography/street`
- `/photography/pets`
- `/photography/project`

摄影内容主要由 `content/photography/` 维护，页面组件在 `src/app/photography/` 和 `src/components/photography/`。

## 目录结构

```text
content/photography/
├── series.json
├── project-meta.json
└── photos/
    ├── street.json
    ├── pets.json
    └── project.json
```

图片文件放在：

```text
public/assets/photos/
├── street/
├── pets/
└── project/
```

## 更新摄影系列文案

文件：`content/photography/series.json`

每个系列对象对应一个分类页：

- `slug: "street"`：街拍
- `slug: "pets"`：宠物
- `slug: "project"`：项目

字段说明：

- `slug`：系列标识，只能是 `street`、`pets`、`project`
- `title`：分类页主标题
- `overline`：标题上方的小字
- `landingSummary`：分类页第一段简介
- `landingDescription`：分类页第二段简介
- `heroLead`：目前保留字段，部分旧组件或后续扩展可用
- `statement`：系列陈述数组，目前保留字段
- `cover`：系列默认封面图
- `href`：系列页面链接
- `ctaLabel`：行动按钮文案，目前部分组件保留
- `featuredPublications`：可选，关联推荐内容

修改系列页开头介绍时，优先改：

```json
"title": "...",
"overline": "...",
"landingSummary": "...",
"landingDescription": "..."
```

## 添加或更新照片

### 街拍黑白选片流程

当前黑白街拍候选图保留在：

```text
conversation/黑白/
```

结构化选片文件是：

```text
conversation/黑白/catalog.json
```

这里记录每张照片的 `score`，当前发布规则是 `score >= 86`。入选照片可以额外设置：

- `order`：网页展示顺序
- `title`：网页标题
- `description`：照片描述
- `publish: false`：即使分数达标也不发布
- `publish: true`：即使分数未达阈值也强制发布

同步街拍页面：

```bash
npm run photos:sync:street
```

这个命令会：

1. 读取 `conversation/黑白/catalog.json`
2. 筛选 86 分及以上的照片
3. 复制入选照片到 `public/assets/photos/street/`
4. 生成 `content/photography/photos/street.json`
5. 清理 `public/assets/photos/street/` 中不再入选的旧图

如果只是调整网页展示顺序，改 `catalog.json` 里的 `order` 后重新运行命令即可。

### 手动添加照片

1. 把照片放进对应目录：

   ```text
   public/assets/photos/street/
   public/assets/photos/pets/
   public/assets/photos/project/
   ```

2. 打开对应 JSON：

   ```text
   content/photography/photos/street.json
   content/photography/photos/pets.json
   content/photography/photos/project.json
   ```

3. 添加照片记录：

   ```json
   {
     "id": "unique-photo-id",
     "title": "照片标题",
     "description": "照片描述",
     "filename": "/assets/photos/street/example.jpg",
     "thumbnail": "/assets/photos/street/example.jpg",
     "width": 1333,
     "height": 2000,
     "takenAt": "May 2026",
     "location": "Hangzhou, China",
     "tags": ["street", "light"]
   }
   ```

字段说明：

- `id`：同一个分类内必须唯一
- `title`：照片标题
- `description`：照片描述
- `filename`：大图路径
- `thumbnail`：缩略图路径；没有单独缩略图时可和 `filename` 相同
- `width` / `height`：图片真实宽高，必须是数字
- `takenAt`：拍摄时间
- `location`：拍摄地点
- `tags`：标签数组

注意：路径从 `/assets/...` 开始，不写 `public`。

## 摄影首页卡片封面

摄影首页 `/photography` 的大卡片封面有一部分直接写在：

```text
src/app/photography/page.tsx
```

常用位置：

- `seriesCardCoverOverride`：覆盖街拍、宠物等系列封面
- `projectCardCovers`：项目卡片多图封面
- `streetCardCovers`：街拍卡片多图封面
- `petsCardCovers`：宠物卡片多图封面

如果只是新增照片，不一定要改这里。只有想改变摄影首页卡片露出的封面图时才需要改。

## 项目页补充信息

文件：`content/photography/project-meta.json`

字段：

- `id`
- `title`
- `titleEn`
- `description`

当前主要作为项目资料保留。若后续项目页需要更多介绍，可继续扩展这个文件。

## 更新后检查

```bash
npm run check:content
npm run typecheck
npm run dev
```

本地检查：

```text
http://localhost:3000/photography
http://localhost:3000/photography/street
http://localhost:3000/photography/pets
http://localhost:3000/photography/project
```

重点检查：

- JSON 是否合法，逗号不要漏
- 新图片是否能显示
- `id` 是否重复
- 图片宽高是否填反
- 移动端两列图片是否裁切正常
