# 爱好内容更新

- `content/hobby/profile.json`：顶部简介、Goodreads/Letterboxd 链接和游戏资料。
- `content/hobby/featured.json`：“我的精选”中的阅读、电影和游戏条目。
- `content/hobby/monthly/YYYY-MM.json`：月度阅读和观影摘要，`month` 必须与文件名一致。

`featured.json` 是唯一精选来源，不存在备用卡片回退。游戏类标题保持“游戏”，页面才会附加 `lolProfile`。首页爱好精选在 `content/site/homepage.json`。

更新后运行 `npm run check:content && npm run typecheck`。
