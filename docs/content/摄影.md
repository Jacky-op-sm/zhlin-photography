# 摄影内容更新

- `content/photography/series.json`：系列文案、缩略名称、默认封面和摄影首页的 `cardCovers`。
- `content/photography/photos/<series>.json`：已发布照片记录，是运行时唯一来源。
- `content/photography/image-manifest.json`：可再生的尺寸/哈希清单，不要手改。

原图放在 `public/assets/photos/<series>/`，页面使用 `public/assets/generated/photos/` 的 WebP 缩略图和大图。完整生成契约见 `docs/assets-workflow.md`。

街拍候选区是 `workspace/photography/street-selection/`：

```bash
npm run photos:preview:street   # 只读预览
npm run photos:publish:street   # 显式发布并生成衍生图
```

发布不会删除源图。手动修改照片记录后运行 `npm run assets:write && npm run check:assets`。
