# 摄影内容更新

- `content/photography/series.json`：系列元数据与相关链接。
- `content/photography/photos/<series>.json`：已发布照片记录，是运行时唯一来源。
- `content/photography/exhibitions/bangkok.json`：Bangkok 摄影展的照片顺序、尺寸与说明。
- `content/photography/image-manifest.json`：可再生的尺寸/哈希清单，不要手改。

生成输入放在 `assets-source/photography/<series>/`，保留版本管理但不作为公共资源提供。页面使用 `public/assets/generated/photos/` 的 WebP 缩略图和大图；Bangkok 已导出的 WebP 位于 `public/assets/photography/bangkok/`。完整生成契约见 [资源工作流](../assets-workflow.md)。

街拍候选区是 `workspace/photography/street-selection/`：

```bash
npm run photos:preview:street   # 只读预览
npm run photos:publish:street   # 显式发布并生成衍生图
```

发布不会删除源图。手动修改照片记录后运行 `npm run assets:write && npm run check:assets`。
