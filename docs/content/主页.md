# 主页内容更新

主页 `/` 的可编辑内容集中在 `content/site/`：

- `homepage.json`：Hero 标题、简介、入口链接，以及摄影/旅行/爱好卡片。
- `profile.json`：姓名、身份、城市、头像、邮箱和社交账号。
- `navigation.json`：Header、Footer 和 sitemap 的公共导航来源。

卡片图片使用 `/assets/...` 公共路径；`href` 必须指向已存在页面。页面组件 `src/app/page.tsx` 只负责布局，不再维护文案数组。

更新后运行：

```bash
npm run check:content
npm run typecheck
```
