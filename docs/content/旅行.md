# 旅行内容更新

每个目的地在 `content/travel/<slug>/` 下只有两个运行时文件：

- `meta.json`：`slug`、`zhName`、`enName`、`period`、`location`、`cardTitle`、`cover`、`hero`、`summary`、`tags`。
- `cards.json`：`spots`、`bookstores`、`food` 三组滑块数据。

`slug` 必须与目录名一致。每张滑块卡包含 `eyebrow`、`title`、`body` 与至少一个 `detailBlocks`；`imageSrc` 和 `imageAlt` 必须成对出现。旅行页会自动发现新目录并依 `period` 排序。

首页的旅行精选在 `content/site/homepage.json`。已停用的长文与迁移中间稿保存在 `workspace/archive/`，不会被页面读取。

更新后运行 `npm run check:content && npm run check:assets`。
