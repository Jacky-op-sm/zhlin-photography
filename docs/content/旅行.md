# 旅行内容更新

摄影展示器的 Travels 栏按 `content/travel/exhibition.json` 中的顺序展出系列和照片。每帧的 `src` 对应目的地 `content/travel/<slug>/cards.json` 中的一张卡片，`width` 和 `height` 填写原图尺寸。

照片说明直接使用卡片的 `imageAlt`、`eyebrow`、`title` 和 `body`。调整顺序时移动选片清单中的记录即可。移出清单的条目仍保存在原游记中，包括原始详情段落和图片。

`/photography#travels` 打开目录，`/photography#travels/wuhan/3` 打开武汉第 3 帧。帧号从 1 开始，随展出顺序变化。首页精选入口在 `content/site/homepage.json`，导航和页脚入口在 `content/site/navigation.json`。

更新后运行 `npm run verify`。
